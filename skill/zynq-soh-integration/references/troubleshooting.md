# 按症状排错

| 症状 | 先取证 | 处理与失效边界 |
|---|---|---|
| 屏幕刷新但命令无效 | UART基址、FIFO有无数据、IRQ配置、原始帧 | 对照能接收的参考工程；ISR和轮询读FIFO需互斥，避免重复或丢字节；不要仅凭TX正常断言RX正常 |
| SD mount错误 | FatFs码、卡检测、电源时钟、PS初始化脚本 | FR_NOT_READY不等于FAT32错误；核对当前BSP和硬件，别先格式化 |
| IP控制寄存器读取停住 | 地址映射、时钟、复位、已加载硬件 | 总线访问本身可能阻塞，外层循环计时不能保护阻塞MMIO |
| DMA一直忙 | TX/RX状态、长度、TLAST、启动顺序、缓存 | 接收先就绪，检查错误位和有界等待；核心自检成功不证明UART/SD链路 |
| IIC 6221 | 这是连续失败次数，不是点数；看新版Exx | 立即重试不代表总线恢复；控制器复位不能释放外设拉低的SDA |
| E01/02/03/05/07～10 | 分别写校准/配置、读状态/校准/测量失败 | 用总线状态或逻辑分析仪区分NACK、超时、未完成；步骤码不是根因 |
| E04/06/11/12/13/14 | 溢出、校准不符、电压重复读不符、分流交叉校验不符、转换超时、时钟配置失败 | 保留无效样本排除，不为消除报错直接放宽校验 |
| recording但不刷新 | 调试器acquisition_stage | 1=IIC，2=TX，3=SD打开，4=写，5=关闭，6=错误显示；不要把固定点位卡住直接归因f_sync |
| 桌面准FPGA不准 | 同一输入逐阶段输出 | 比较通道顺序、单位、归一化、舍入、Q格式和状态复位；先消除输入差异再评价量化 |

验证至少覆盖阈值附近、异常打断稳定计数、短写/读失败、相同输入连续调用两次、串口分段和噪声、不同采样长度的重采样首尾。模拟通过不能保证真实SD或IIC长时间可靠。
